# SPOTV NOW Golf 친구초대 이벤트 데모 — Ver.2

기획 검토용 정적 데모입니다(실서비스 아님). `index.html` 한 파일로 동작하며, 입력값은 브라우저 localStorage(`golfInviteDemo.ver2`)에만 저장됩니다.
Ver.1은 옆 폴더 `golf-invite-demo/`에 그대로 보존되어 있습니다.

## 화면
| 주소 | 화면 |

| `#/` | 이벤트 메인 |

## Ver.1 대비 바뀐 점 (11.25 피드백 · 11.26 회의)
- **이벤트가 주인공**: 첫 화면에 이벤트 기간, 이벤트명("프로는 팀 매치! 우리는 라운드 팀!"), 내용, 이벤트 이미지(골프장 사진 + 4명 팀 + 라운드권 3팀 티켓), 메인 CTA를 둡니다. 대회 정보는 아래로 내렸습니다.
- **섹션 순서**: 이벤트 → 경품 → 참여 방법(내 팀 현황 · 초대 방법 · 응모 규칙) → 12월 대회 정보 → 유의사항.
- **CTA "친구 초대하고 나만의 팀 꾸리기"**: 비로그인은 로그인/회원가입으로 이동하고, 로그인 후 메인으로 돌아오면 초대코드 창이 바로 뜹니다. 로그인 상태면 누르는 즉시 초대코드를 표시합니다.
- **응모 규칙**: 초대코드를 만든 사람과 가입한 친구 모두 추가 경품에 자동 응모됩니다. 라운드권은 대표자(코드 만든 사람)에게 지급하고 대표자 팀 4명이 함께 이용합니다. 4명 팀을 완성하면 추가 경품 당첨 확률이 올라갑니다. 이 내용을 표로 정리했습니다.
- **내 팀 현황**: 0~4명, 빈 자리 수마다 다른 안내 문구를 보여 줍니다.
- **대회 정보** (작은 제목 "이후 대회 정보"): 대회별 버튼은 알림 신청 → LIVE → 하이라이트/다시보기 순으로 바뀝니다. PNC는 대표 선수 8명의 프로필 사진을 넣었습니다. PGA 프로모 영상 자리(추후 삽입)는 PNC까지 끝난 뒤(대회 종료 후 단계부터)에만 나타납니다.
- **경품 영역**: 참고 시안처럼 작은 가로형 카드로 줄였습니다(메인 · 내 팀 현황 공통).
- **데모 도구**: 친구 추가와 함께 "마지막 친구 제거"를 넣었습니다. 3명 미만이 되면 응모 완료와 코드 마감이 풀립니다.
- **대회 종료 후(12.22~1.17)**: 이벤트는 그대로 유지하고, 대회 영역만 "다시보기"로 바뀝니다.
- **이벤트 종료(1.18~)**: CTA는 비활성화되고, 초대 링크로 들어오면 종료 안내가 나옵니다.
- **회원가입(초대 링크)**: 초대장 카드와 "가입하면 이런 혜택이 있어요" 섹션을 추가했습니다.
- **경품 수량** (참고 시안 기준):
  - 롯데시네마 관람권 1인 2매 100명 (신규)
  - 드라이버 커버 3명
  - 볼빅 골프공 30명 (Ver.1은 10명)

## 확인 필요
- 이벤트 기간(12.14~1.17)과 중계 시간(12.17 오전 9시, 12.21 오전 2시)은 예시입니다.
- 관람권 응모 대상이 정해지지 않았습니다.
  - 참고 시안의 유의사항: "팀 완성자 중"
  - 참고 시안의 가입 화면: "가입 즉시"
  - 데모에서는 "응모자 모두"로 통일했습니다.
- 팀 완성 시 당첨 확률을 얼마나 올릴지 정해야 합니다.
- 관람권 발송 방식(우편)과 당첨자 발표 일정을 정해야 합니다.
- "SPOTV NOW Golf 콘텐츠 무료" 문구는 참고 시안에 있었지만, 확인이 필요해 데모에서는 뺐습니다.
- 이미지 사용 허락이 필요합니다.
  - PNC 선수 사진: PGA TOUR · LPGA 공식 프로필
  - 키 비주얼: 골프채널
  - 골프장 사진
- 관람권 이미지는 직접 그린 임시 그림입니다(로고 없음).
