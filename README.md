# SPOTV NOW Golf 친구초대 이벤트 — 기획 검토용 데모

빌드가 필요 없는 정적 페이지입니다(`index.html` 1개). 배포 방법은 `VERCEL_GUIDE.md`를 참고하세요.

> 기획 검토용 DEMO입니다. 실제 서비스가 아니며, 입력값은 브라우저 `localStorage`에만 저장되고 외부로 전송되지 않습니다.
> 로고는 공식 SPOTV NOW Golf 로고(`assets/spotvnow-golf-logo-w.png`)를 사용합니다.

## 이벤트 규칙
- 초대한 사람(A) 포함 **4명이 한 팀**이 되면 자동 응모됩니다.
- A는 **최대 3명**까지 초대할 수 있습니다. 3명이 가입을 마치면 자동 응모되고, A의 초대코드는 **마감(비활성화)**됩니다.
- 초대 링크는 회원가입 페이지로 바로 연결됩니다: `#/signup?ref=CODE`. 예전 링크 `#/i/CODE`도 회원가입으로 넘어갑니다.
- 연계 대회: 2026 PGA 투어 옵텀 골프채널 게임스(미국 12.16 수 저녁 = 한국 12.17 목 오전, 4대4 팀 대항전).
  - 팀 로리: 로리 매킬로이(주장), 맷 피츠패트릭, 김시우, 리하오퉁
  - 팀 스코티(지난해 우승): 스코티 셰플러(주장), 크리스 고터럽, 마이클 브레넌, 잭슨 코이번
  - 출처: 골프채널 2026.11.2 보도자료, 골프매거진코리아 2026.11.3 기사, Golf Channel 2025 라이브 기사(지난해 결과)

## 실제 서비스 위치와 참고 페이지
- 이 페이지는 spotvnowgolf.co.kr 상단 GNB의 **'아시안스윙' 자리**에 들어갑니다. **GNB 메뉴명은 미정**이라, 헤더 왼쪽 이벤트명을 `index.html`의 `EVENT_NAME` 값('친구초대 이벤트', 임시) 하나로 관리합니다.
- 헤더 구성은 `spotvnowgolf.co.kr/asian-swing` 서브 사이트와 같은 틀을 따릅니다. 왼쪽에 이벤트 로고, 가운데에 메뉴, 오른쪽에 SPOTV NOW Golf로 가는 버튼이 있습니다. 오른쪽 버튼 "SPOTV NOW Golf에서 중계 보기"는 새 창으로 열리고 `utm_source=golf-invite`가 붙습니다.
- 푸터는 `spotvnowgolf.co.kr/golf` 푸터와 같은 문구·구성입니다(2026.11.25 확인).

## 디자인시스템 적용 내용
- 기준: `ds5/project` (tokens.json, components/bundle.css 최신본, README 브랜드 규칙).
- `tokens.json` → `:root { --이름: 값 }` CSS 변수로 변환해 인라인(색, 글꼴 패밀리, 타이포 단축값 `--type-*`, 간격, 반경, 크기). `bundle.css`도 그대로 인라인했고, 번들 안의 리터럴 색 3곳(선택 칩 글자, 오늘 배지 배경, 표 헤더 30% 글자)만 토큰 변수로 치환했습니다. 페이지 CSS의 hex 값은 /golf 푸터를 그대로 옮긴 색(`#2a2a2a` 구분선, `#6a6a6a` 글자, 맨 위로 버튼 `#1a1a1a`·`#484848`)뿐입니다.
- 글꼴: Pretendard(jsDelivr `orioncactus/pretendard@v1.3.9` 정적 CSS). 네트워크가 막히면 시스템 글꼴로 대체됩니다.
- 색 역할: `brand`(오렌지)는 주요 CTA, D-day 숫자, 현재 위치(GNB 활성 메뉴, 팀 칸의 "나"), 체크된 체크박스·스테퍼, 자동응모 완료 표시, 이벤트 연계 대회 카드 테두리·태그에만 사용. `live`·`vod`는 쓰지 않음. 장식용 오렌지 면 없음.

## 미확정 사항 (데모에서 가정한 값)
1. 라운드 경품 당첨 대상: 팀원 4명 모두 / 팀 대표 1명. 기본값은 '팀원 4명 모두'이며 데모 도구에서 바꿀 수 있습니다.
2. 추가 경품(PGA 드라이버 커버 3명, 볼빅 골프공 10명): 인원은 요청대로 임의로 정했습니다. 추첨 대상은 "자동 응모된 참여자 중 추첨"으로 가정했습니다.
3. 파인비치 호텔 숙박 50% 할인: "파인비치 라운드 당첨 팀에게 제공"으로 가정했습니다.
4. 이벤트 기간: 예시값(~2026.12.16). 옵텀 골프채널 게임스 편성 시간은 "추후 안내"로 표기했고, 참고로 "지난해 오전 9시 30분쯤 시작"을 적었습니다.
5. 만료 코드의 기준(이벤트 종료, 지난 이벤트 코드 등): 데모는 샘플 코드 1개로만 보여 줍니다.
6. 로그인 방식: 앱 딥링크 인증 후 웹 복귀 vs 웹 직접 로그인. 기본은 '둘 다' 노출
7. 중복 가입 방지 기준: 데모는 이메일·휴대폰 번호로 확인. 실서비스는 본인인증 CI 기준 권장
8. GNB 메뉴명: 미정. 임시로 '친구초대 이벤트'(`EVENT_NAME`)를 씁니다.
9. 2026 대회 세부 규칙: 골프채널이 아직 공개하지 않았습니다. 팀 릴레이·14클럽 챌린지(2026 확정)와 새 게임(2026 신규)만 확인됐고, 규칙 설명은 모두 2025년 방식입니다. 공개되면 `RULES` 값을 바꿔 주세요.
10. 중계 투어의 "이번 주/최근 중계" 대회명은 2026.11.25 /golf 중계 일정 기준입니다.
