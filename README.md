# SPOTV NOW Golf 친구초대 이벤트 — 기획 검토용 데모

빌드가 필요 없는 정적 페이지입니다(`index.html` 1개). 배포 방법은 `VERCEL_GUIDE.md`를 참고하세요.

> 기획 검토용 DEMO입니다. 실제 서비스가 아니며, 입력값은 브라우저 `localStorage`에만 저장되고 외부로 전송되지 않습니다.
> 로고는 공식 SPOTV NOW Golf 로고(`assets/spotvnow-golf-logo-w.png`)를 사용합니다.

## 이벤트 규칙
- 초대한 사람(A) 포함 **4명이 한 팀**이 되면 자동 응모됩니다.
- A는 **최대 3명**까지 초대할 수 있습니다. 3명이 가입을 마치면 자동 응모되고, A의 초대코드는 **마감(비활성화)**됩니다.
- 초대 링크는 회원가입 페이지로 바로 연결됩니다: `#/signup?ref=CODE`. 예전 링크 `#/i/CODE`도 회원가입으로 넘어갑니다.
- 연계 대회: 2026 PGA 투어 옵텀 골프 채널 게임즈(12.17 목, 팀 대항전).

## 디자인시스템 적용 내용
- 기준: `ds5/project` (tokens.json, components/bundle.css 최신본, README 브랜드 규칙).
- `tokens.json` → `:root { --이름: 값 }` CSS 변수로 변환해 인라인(색, 글꼴 패밀리, 타이포 단축값 `--type-*`, 간격, 반경, 크기). `bundle.css`도 그대로 인라인했고, 번들 안의 리터럴 색 3곳(선택 칩 글자, 오늘 배지 배경, 표 헤더 30% 글자)만 토큰 변수로 치환했습니다. 페이지 CSS에는 hex 값이 없습니다.
- 글꼴: Pretendard(jsDelivr `orioncactus/pretendard@v1.3.9` 정적 CSS). 네트워크가 막히면 시스템 글꼴로 대체됩니다.
- 색 역할: `brand`(오렌지)는 주요 CTA, 현재 위치(GNB 활성 메뉴, 팀 칸의 "나"), 체크된 체크박스·스테퍼, 자동응모 완료 카드 테두리, 이벤트 연계 대회 태그에만 사용. `live`·`vod`는 쓰지 않음. 장식용 오렌지 면 없음.
- 이미지(`assets/`, 사내 기존 홍보물에서 가져옴):
  - `spotvnow-golf-logo-w.png`: `서비스기획팀/SPOTV NOW Golf LOGO_W.png`
  - `kv-pga-tour.jpg`: `202512_신규 골프 플랫폼/.../PGA메인큐레이션.jpg` (1280×720)
  - `pga-2026-live.jpg`: `202602_[KR][Golf] 100원 프로모션/2026_PGA_정방형_로고수정.png` (720×720으로 축소)
  - 옵텀 골프 채널 게임즈·PNC 챔피언십·볼빅·골프장 로고는 사내 자료에 없어 글자로만 표기했습니다. 선수 사진이 들어간 이미지라 외부 공개 전 사용 범위를 확인해 주세요.
- 문구: 안내는 "~해 주세요." 존댓말, 버튼은 동사 하나("초대코드 만들기", "가입하기", "복사하기", "공유하기", "다음"), 이모지 제거, 빈 목록은 "아직 가입한 친구가 없습니다".
- 이름은 첫 글자 뒤를 모두 마스킹(홍**) — UserMenu 규칙.
- 접근성: 본문은 text-250/text-300(대비 5.9:1 이상) 사용, placeholder에 필수 정보 없음(모든 입력에 `<label for>`), 오렌지 버튼 라벨 16px/700 이상, 포커스 링 2px `brand`, 진행률 `role="progressbar"`, 토스트 `aria-live`, 스테퍼 `aria-current="step"`.
- 오류 표시: 디자인시스템에 오류 색이 없어(README "아직 없는 것") 오류는 `text-100` 굵은 글씨 + "!" 원형 표식으로 표시합니다.

## 데모 도구 (우측 하단 "데모 도구")
- 친구 가입 시뮬레이션: 로그인한 사용자의 코드로 가상 친구 가입 → 팀 인원 증가, 3명이 차면 자동 응모와 코드 마감 확인(마감 후 버튼 비활성)
- 가입 분기 미리보기: 샘플 링크로 회원가입 화면 열기
  - 유효 `#/signup?ref=GNTEAM01` (김** 님 팀 2/4명)
  - 마감 `#/signup?ref=GNFULL03` (박** 님 팀 4/4명, 응모 완료)
  - 만료 `#/signup?ref=GN25PAST`
  - 잘못된 코드 `#/signup?ref=GNNOPE00`
  - 샘플 초대자는 페이지를 열 때 자동으로 만들어지므로 위 링크를 바로 공유해도 됩니다.
- 라운드 경품 당첨 대상 전환: 팀원 4명 모두 / 팀 대표 1명
- 로그인 방식 전환: 앱 / 웹 / 둘 다
- 화면 바로가기(내 초대 링크 포함), 데이터 초기화
- 저장 키가 `golfInviteDemo.v2`로 바뀌어 이전 데모 데이터는 이어지지 않습니다.

## 미확정 사항 (데모에서 가정한 값)
1. 라운드 경품 당첨 대상: 팀원 4명 모두 / 팀 대표 1명. 기본값은 '팀원 4명 모두'이며 데모 도구에서 바꿀 수 있습니다.
2. 추가 경품(PGA 드라이버 커버 3명, 볼빅 골프공 10명): 인원은 요청대로 임의로 정했습니다. 추첨 대상은 "자동 응모된 참여자 중 추첨"으로 가정했습니다.
3. 파인비치 호텔 숙박 50% 할인: "파인비치 라운드 당첨 팀에게 제공"으로 가정했습니다.
4. 이벤트 기간: 예시값(~2026.12.16). 옵텀 골프 채널 게임즈 편성 시간은 "추후 안내"로 표기했습니다.
5. 만료 코드의 기준(이벤트 종료, 지난 이벤트 코드 등): 데모는 샘플 코드 1개로만 보여 줍니다.
6. 로그인 방식: 앱 딥링크 인증 후 웹 복귀 vs 웹 직접 로그인. 기본은 '둘 다' 노출
7. 중복 가입 방지 기준: 데모는 이메일·휴대폰 번호로 확인. 실서비스는 본인인증 CI 기준 권장
